# Django Mailing Application (Сервис управления рассылками)

Полнофункциональное веб-приложение на Django для создания, управления и автоматической отправки email-рассылок клиентам. Проект включает в себя ролевую модель (RBAC), двухуровневое кэширование с использованием **Redis**, систему логирования попыток отправки и безопасную аутентификацию.

---

## 🚀 Основной функционал

- **Управление рассылками:** Создание рассылок с гибким графиком, текстом сообщений и темами.
- **База клиентов:** Управление списком получателей (добавление, редактирование, удаление).
- **Попытки рассылок (Логирование):** Автоматическая фиксация статусов отправки (успешно / ошибка) с сохранением ответов сервера.
- **Ролевая модель (RBAC):** 
  - *Обычный пользователь:* управление собственными рассылками и клиентами.
  - *Менеджер:* просмотр всех рассылок и списка пользователей, возможность блокировки пользователей и отключения рассылок.
- **Кэширование:**
  - *Высокоуровневое:* кэширование страниц с помощью встроенных механизмов Django.
  - *Низкоуровневое:* кэширование статистики дашборда через **Redis** (`django-redis`).
- **Аутентификация и безопасность:** Регистрация, подтверждение почты, авторизация и восстановление пароля.

---

## 🛠 Технологии и стек

- **Backend:** Python, Django 6.1
- **Управление пакетами:** Poetry
- **База данных:** PostgreSQL
- **Кэширование:** Redis
- **Конфигурация:** `python-dotenv` (переменные окружения)

## ⚙️ Инструкция по установке и запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/Sergey-Shinkevich/newsletter_project.git
cd newsletter_project
```
### 2. Установка зависимостей через Poetry
Poetry автоматически создаст виртуальное окружение и установит все необходимые библиотеки:

```Bash
poetry install
```
### 3. Активация виртуального окружения
```Bash
poetry shell
```
### 4. Настройка переменных окружения
Создайте файл .env в корне проекта (рядом с pyproject.toml и manage.py) и 
заполните его по шаблону env_template

### 5. Запуск Redis
Убедитесь, что сервер Redis запущен и доступен локально на порту 6379.

### 6. Применение миграций базы данных
```Bash
python manage.py makemigrations
python manage.py migrate
```
### 7. Запуск сервера разработки
```Bash
python manage.py runserver
```
После запуска приложение будет доступно по адресу: http://127.0.0.1:8000/
